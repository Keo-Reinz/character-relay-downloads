# Character Relay

Host a two-player guess-the-character game with private character cards, concise descriptions and shared clues. Games first, then anime and other media.

## Downloads and updates

[Windows beta releases](https://github.com/Keo-Reinz/character-relay-downloads/releases)

- **K-Projects users:** open Character Relay in an updated launcher, choose Check for updates, then Update. Quit the app before updating. Saved libraries remain separate.
- **Standalone:** download the ZIP ending in `windows-x64-standalone.zip`, extract it, then run `Start Character Relay.cmd`. It includes Node.js.
- The smaller `windows-x64.zip` is the app-only package for K-Projects; it requires the launcher runtime.

This repository contains downloads and release notes. Application source is maintained separately in a private repository. Source commits do not update installed copies: published GitHub Releases do.

## Data and credits

Libraries, favourites and round history are stored locally. Online searches contact the configured public character databases; no account is required. Character images and source content belong to their respective rights holders. Attribution is included in each package. This is an unofficial fan tool.
